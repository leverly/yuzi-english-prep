这些不是难词，是最基础的词。最短 3 个字母（cut / map / big）。 所以音标题的失分不是「不认识」，是「拼不对」。
解题与备考

按易错点归成 16 类

解题动作：看音标 → 定音节 → 拼字母 → 查形式

解题四步

  • 看音标定元音。先确定重读元音是哪个字母组合（短元音 ɪ / 短元音 æ / ee 组合 是最常见的三类）。
  • 数音节。4.4 个字母平均 1–2 个音节，音节数对不上就是拼错了。
  • 查辅音丛。spring 的 spr、driver 的 dr、smell 的 sm——漏一个字母就零分。
  • 查形式。空前有 a / an 还是复数？句子的时态要不要加 -s / -ed？这一步最容易丢分。

备考三步

  • 不背整本词表。按上面 16 类特征分批练，先练词数最多的三类。
  • 听写而不是默看。看着单词背是「认读」，听写才是「拼写」——考的是后者。
  • 错词进本子，隔日回抽。当天对的题不算掌握，隔一天还能写对才算。
